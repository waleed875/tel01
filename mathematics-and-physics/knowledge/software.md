# هندسة البرمجيات
## الخوارزميات وهياكل البيانات
الخوارزمية وصف محدود للخطوات التي تحول المدخلات إلى مخرجات. تقاس كلفة الزمن والذاكرة غالبًا برمز Big O. البحث الثنائي يعمل على قائمة مرتبة بزمن O(log n). اختبر الحالات الطرفية وتأكد من صحة النتيجة.
## البرمجة بلغة Python
استخدم الدوال الصغيرة، أنواع البيانات، الاختبارات الوحدوية، الاستثناءات، وبيئات Python الافتراضية. فرق بين الخطأ المنطقي والخطأ النحوي. لا تنفذ شيفرة مجهولة داخل البوت.
## الأنظمة المدمجة
تستخدم لغة C وC++ لبرمجة المتحكمات الدقيقة. يجب فهم المؤقتات والمقاطعات وواجهات UART وSPI وI2C، مع مراعاة قيود الذاكرة والتوقيت.
