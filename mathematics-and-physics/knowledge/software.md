# هندسة البرمجيات
## الخوارزميات
الخوارزمية خطوات محددة تحول المدخلات إلى مخرجات. البحث الثنائي على بيانات مرتبة يأخذ O(log n).
## Python
تساعد الاختبارات الوحدوية وبيئات التشغيل الافتراضية والتعامل الواضح مع الاستثناءات على موثوقية البرامج.
## الأنظمة المدمجة
تستخدم C وC++ للمتحكمات الدقيقة؛ افهم المقاطعات والمؤقتات وواجهات UART وSPI وI2C.
