# أستاذ الرياضيات والفيزياء — بوت تلغرام

بوت تعليمي بالعربية: شرح رياضيات وفيزياء حسب المستوى، حل المسائل النصية وبالصور، اختبارات متعددة الخيارات مع تصحيح فوري، وإحصاءات تقدم في SQLite.

## 1. إنشاء بوت تلغرام

1. افتح [@BotFather](https://t.me/BotFather) داخل تلغرام.
2. أرسل `/newbot` واتبع الخطوات لإنشاء اسم واسم مستخدم ينتهي بـ `bot`.
3. انسخ **التوكن** وضعه في `TELEGRAM_BOT_TOKEN` داخل `.env`. لا تنشره على GitHub.

## 2. مفتاح الذكاء الاصطناعي (اختياري للاختبارات، مطلوب للشرح والصور)

1. افتح [OpenAI API keys](https://platform.openai.com/api-keys) وأنشئ مفتاح API.
2. ضع المفتاح في `OPENAI_API_KEY` داخل `.env`، واستخدم نموذجًا متاحًا لحسابك.
3. انتبه: استخدام API يُحاسب منفصلًا عن اشتراك ChatGPT. راجع إعدادات الفوترة وحدود الاستخدام في المنصة.

## 3. التشغيل على Windows

**الأسهل:** ثبّت Python 3.11 أو أحدث، فك ضغط المشروع، ثم شغّل `run_windows.bat` بالنقر المزدوج. في أول تشغيل سيفتح ملف `.env` لتضع المفاتيح؛ احفظه وشغّل الملف مرة أخرى.

أو يدويًا في PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python bot.py
```

في Linux/macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# edit .env
python bot.py
```

**للعمل طوال الوقت:** يجب إبقاء الجهاز والبرنامج يعملان، أو استضافة المشروع على سيرفر/VPS. التشغيل الحالي عبر long polling لا يحتاج نطاقًا أو Webhook.

## 4. التشغيل باستخدام Docker

```bash
cp .env.example .env
# edit .env
docker compose up --build -d
docker compose logs -f
```

على Windows، يمكنك إنشاء `.env` يدويًا بدل `cp`. قاعدة البيانات تستمر في مجلد `data/`.

## أوامر البوت

| الأمر | الوظيفة |
|---|---|
| `/start` | القائمة الرئيسية |
| `/math`, `/physics` | تغيير المادة |
| `/level` | اختيار ابتدائي/متوسط/ثانوي/جامعي |
| `/lesson المشتقات` | شرح درس معين، أو `/lesson` لدرس مقترح |
| `/quiz` | سؤال من بنك أسئلة غير معتمد على API |
| `/progress` | عدد الإجابات الصحيحة ونسبتها |
| `/new` | مسح سياق الحوار السابق مع إبقاء التقدم |
| `/delete_data` | حذف بيانات الطالب من قاعدة بيانات البوت |

يمكن إرسال نص أو صورة لمسألة، مع تعليق اختياري للصورة. الصور تُرفع إلى OpenAI إذا تم تفعيل المفتاح. تُحفظ الأسئلة والأجوبة النصية الأخيرة فقط محليًا لاستمرار السياق؛ لا تخزن الصور في قاعدة البيانات. خدمة OpenAI قد تعالج المحتوى وفق إعدادات حساب API. استعمل البوت على محادثة خاصة.

## إعدادات `.env`

- `TELEGRAM_BOT_TOKEN`: رمز البوت الإلزامي.
- `OPENAI_API_KEY`: لتفعيل الشرح وتحليل الصور، وإلا تعمل الاختبارات فقط.
- `OPENAI_MODEL`: افتراضيًا `gpt-6.1-terra`؛ قد يختلف التوافر بحسب حساب API.
- `DAILY_AI_LIMIT`: حد طلبات AI لكل مستخدم يوميًا، افتراضيًا 25. يعاد ضبطه منتصف الليل بتوقيت UTC.
- `DATABASE_PATH`: مسار قاعدة البيانات، افتراضيًا `data/students.sqlite3`.

## ملاحظات التشغيل والأمان

- النسخة موجهة لبوت صغير؛ للانتشار الكبير ينصح PostgreSQL وRedis وWebhook وتسجيل نتائج مفصل ولوحة إدارة.
- الأسئلة المدرجة 24 سؤالًا (3 لكل مادة ومستوى). يمكن توسيعها في `questions.py`.
- الصور والنصوص التي تطلب شرحًا تُرسل إلى API؛ هذا يستهلك رصيدًا وقد تكون هناك أخطاء في الشرح؛ تحقق من النتائج المهمة.
- مفاتيح `.env` وقاعدة البيانات مستثناة من Git. لا ترسل مفاتيحك داخل الدردشة أو تسجلها في المستودع.
- حد الاستخدام اليومي حماية مبدئية وليس بديلًا عن إعداد حد إنفاق حساب API ومراقبة الفواتير.
- الإصدار الأول لا يعالج الصوت أو PDF.
